# Compressor (Rust + Slint, Android 8+)

فشرده‌سازی عکس و ویدیو با درصد دلخواه (۵ تا ۹۰). خروجی در `DCIM/Compress` با همان نام فایل اصلی ذخیره می‌شود.

## راه‌اندازی یک‌باره
1. یک **fine-grained Personal Access Token** بساز با دسترسی **Secrets: Read and write** فقط روی این ریپو، و نام آن را `ADMIN_PAT` در Secrets ریپو بگذار.
2. از تب Actions، workflow با نام `setup-keystore` را یک‌بار اجرا کن. keystore ساخته و در Secrets ذخیره می‌شود.
3. از این به بعد هر push روی `main` یک Release با APK های `arm64-v8a` و `armeabi-v7a` می‌سازد.

## نکات امنیتی
- keystore و رمز آن فقط در GitHub Secrets هستند و در ریپو نیستند. اگر این secret پاک شود، نسخه‌های جدید روی نسخه‌های قبلی نصب نمی‌شوند.
- این ریپو عمومی است؛ هیچ کلید یا رمزی داخل کد نیست. فقط افرادی که دسترسی push دارند می‌توانند workflowها را اجرا کنند، پس دسترسی را محدود نگه دار.
- ffmpeg با libx264 (GPL) ساخته می‌شود. چون سورس این ریپو عمومی است، الزام GPL برای انتشار APK برآورده می‌شود.

## آپلود زیپ
فایل زیپ را در پوشه `uploads/` بگذار و push کن. workflow محتوا را استخراج و فایل‌ها را جایگزین می‌کند.
